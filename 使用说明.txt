小团搜题 v1.0.0  使用说明
=================================

【是什么】
截一小块屏幕，自动 OCR + 调 AI，把答案和解析浮在最上层。
不需要题库，任何题都能问。

【首次使用】
1. 双击「小团搜题」启动
2. 第一次会弹出设置：选服务商 → 填 API Key → 点「测试连接」
   看到 ✅ 再点保存（DeepSeek 端点：https://api.deepseek.com/v1，模型 deepseek-chat）
3. 点「框选区域」，拖一个框把题目框住
4. 点「开始」

【热键（全局，切到别的窗口也能用）】
F1  重新框选区域
F2  暂停 / 继续
F3  立即识别一次
F4  重问（换一种说法再解一次）
F5  显示 / 隐藏答案窗

【界面说明】
- 左上小圆点：灰=待机 蓝=识别/请求中 绿=完成 黄=提示 红=出错
- 下方日志：每一步耗时都会写（OCR 0.7s + AI 1.4s ≈ 2.1s）
- 答案窗：可拖动、可复制、可折叠

【常见问题】
1. 热键没反应 → 右键以管理员身份运行
2. 一直"没读到文字" → 区域框得太小/太暗，重新 F1 框一次
3. 答案窗挡住题目 → 脚本截图时会自动把它藏起来，不会读到自己
4. 想省钱/离线 → 设置里选「Ollama 本地」，端点 http://127.0.0.1:11434/v1

【文件位置】
配置：exe 同目录 config.json
历史：exe 同目录 history.jsonl

【卸载】
Inno 安装的：设置 → 应用 → 小团搜题 → 卸载
绿色版：删掉文件夹即可
